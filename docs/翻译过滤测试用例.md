### ❌ 应该翻译的内容

#### 1. 英文短语（2 个单词以上）
- `Hello world` → 你好世界
- `Click here` → 点击这里
- `Submit form` → 提交表单
- `Welcome to our website` → 欢迎来到我们的网站

#### 2. 英文句子
- `This is a test.` → 这是一个测试。
- `Please click the button.` → 请点击按钮。

#### 3. 包含中文的混合内容
- `Hello 你好` → 需要翻译
- `README 文件` → 需要翻译

## 测试方法

### 单元测试代码

```javascript
const testCases = [
    // 应该过滤的
    { input: 'README.md', expected: false },
    { input: 'CHANGELOG.md', expected: false },
    { input: 'Dockerfile', expected: false },
    { input: 'nsis_locales', expected: false },
    { input: 'cicd_scripts', expected: false },
    { input: 'Free-Deompiler.com website', expected: false },
    { input: 'free-decompiler.com', expected: false },
    { input: 'https://github.com', expected: false },
    { input: 'user@example.com', expected: false },
    { input: '/usr/bin/node', expected: false },
    { input: 'TranslationUtils', expected: false },
    { input: 'npm install', expected: false },
    { input: 'Hello', expected: false },
    { input: '...', expected: false },
    
    // 应该翻译的
    { input: 'Hello world', expected: true },
    { input: 'Click here', expected: true },
    { input: 'This is a test', expected: true },
    { input: 'Welcome to our website', expected: true }
];

// 运行测试
testCases.forEach(({ input, expected }) => {
    const result = shouldTranslateText(input);
    const status = result === expected ? '✓' : '✗';
    console.log(`${status} "${input}" => ${result} (expected: ${expected})`);
});
```

## 边界情况

### 需要注意的边界案例

1. **带版本号的文件名**
   - `README.v2.md` → 应该过滤 ✓
   - `CHANGELOG.2024.md` → 应该过滤 ✓

2. **带路径的文件名**
   - `src/README.md` → 应该过滤（作为路径）✓
   - `./package.json` → 应该过滤（作为路径）✓

3. **域名 + 描述**
   - `Free-Deompiler.com website` → 应该过滤 ✓
   - `github.com repository` → 应该过滤 ✓
   - `example.com page` → 应该过滤 ✓

4. **混合内容**
   - `Visit github.com for more` → 应该翻译（整句）
   - `See README.md file` → 应该翻译（整句）

## 性能考虑

- 所有正则表达式应该在 **1ms** 内完成
- 总体过滤逻辑应该在 **5ms** 内完成
- 不应该影响页面滚动或交互
