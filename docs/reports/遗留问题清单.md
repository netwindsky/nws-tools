### 3. TranslationUtils.js - 缺少划词翻译专用方法

**文件**: `js/modules/features/translation/TranslationUtils.js`  
**行号**: 123（调用处）

**问题描述**:
- 缺少 `shouldTranslateSelectedText()` 方法
- 只有 `shouldTranslateText()`（用于页面翻译），但划词翻译需要更宽松的过滤规则

**影响**: 划词翻译的文本过滤功能失效

**修复建议**:
```javascript
// 添加新方法
shouldTranslateSelectedText(text) {
    // 划词翻译使用更宽松的规则
    const normalized = this.normalizeText(text);
    if (!normalized || normalized.length < 2) return false;
    
    // 只过滤明显的无意义内容（如纯符号）
    // 保留 URL、邮箱等（用户可能确实想翻译这些）
    return !/^[^a-zA-Z0-9\u4e00-\u9fa5]+$/.test(normalized);
}
```

**TranslationView.js** - 添加复制方法:
```javascript
copyToClipboard() {
    if (!this.currentOriginalText || !this.currentTranslatedText) return;
    
    const content = `原文：${this.currentOriginalText}\n\n翻译：${this.currentTranslatedText}`;
    navigator.clipboard.writeText(content).then(() => {
        // 显示成功反馈
        this.showCopyToast('已复制到剪贴板');
    }).catch(err => {
        console.error('复制失败:', err);
    });
}

showCopyToast(message) {
    // 创建 Toast 提示
    const toast = document.createElement('div');
    toast.className = 'nws-copy-toast';
    toast.innerHTML = `
        <svg viewBox="0 0 24 24" width="20" height="20">
            <path fill="currentColor" d="M9 16.17L4.83 12l-1.42 1.41L9 19 21 7l-1.41-1.41z"/>
        </svg>
        ${message}
    `;
    document.body.appendChild(toast);
    
    setTimeout(() => toast.classList.add('nws-copy-toast-show'), 10);
    setTimeout(() => {
        toast.classList.remove('nws-copy-toast-show');
        setTimeout(() => toast.remove(), 300);
    }, 2000);
}
```
