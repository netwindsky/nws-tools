# 日期时间格式多行文本修复

## 问题描述

**现象**：
```
HTML 结构：
<div>
  Updated
  <span>15 hours ago</span>
</div>

结果：仍然被翻译 ❌
```

---

## 根本原因

### 文本节点被分割

**HTML 结构**：
```html
<div>
  Updated          ← 文本节点 1
  <span>
    15 hours ago   ← 文本节点 2
  </span>
</div>
```

**提取过程**：
```javascript
// PageManager.getTextItems(element)
items = [
  { node: textNode1, original: "Updated", normalized: "Updated" },
  { node: textNode2, original: "15 hours ago", normalized: "15 hours ago" }
]

// 合并文本
fullText = items.map(i => i.normalized).join('\n');
// 结果："Updated\n15 hours ago"
```

### 检测失败

**原始检测逻辑**：
```javascript
isDateTime(text) {
    const relativeTimeRegex = /^(updated|created|...)\s+\d+\s+(second|minute|...)\s+ago$/i;
    return relativeTimeRegex.test(text);  // 测试 "Updated\n15 hours ago"
}
```

**失败原因**：
```
文本："Updated\n15 hours ago"
正则：/^(updated|...)\s+\d+\s+(second|...)\s+ago$/i

问题：
1. ^ 匹配行首 → "Updated"
2. $ 匹配行尾 → "ago"
3. 但中间有 \n 换行符
4. 正则中的 \s 不匹配换行符（默认模式）
5. 匹配失败 ❌
```

---

## 修复方案

### 1. 支持多行文本处理

**新增 `isDateTime` 方法处理多行**：
```javascript
isDateTime(text) {
    if (!text) return false;
    
    // 处理多行文本：按行分割，每行单独检测
    const lines = text.split('\n').map(line => line.trim()).filter(line => line.length > 0);
    
    // 如果只有 1 行，直接检测
    if (lines.length === 1) {
        return this.isDateTimeLine(lines[0]);
    }
    
    // 如果有多行，合并后检测
    // 例如："Updated\n15 hours ago" → "Updated 15 hours ago"
    const combinedText = lines.join(' ');
    return this.isDateTimeLine(combinedText);
}
```

**处理流程**：
```
输入："Updated\n15 hours ago"

步骤 1: 分割行
lines = ["Updated", "15 hours ago"]

步骤 2: lines.length = 2 (多行)

步骤 3: 合并行
combinedText = "Updated 15 hours ago"

步骤 4: 检测单行
isDateTimeLine("Updated 15 hours ago") → true ✓
```

### 2. 新增动词 + 绝对日期格式

**问题**：
```
HTML:
<div>
  Updated
  <span>Mar 5, 2026</span>
</div>

合并后："Updated\nMar 5, 2026"
```

**新增正则**：
```javascript
isDateTimeLine(text) {
    // ... 其他正则
    
    // 8. 动词 + 绝对日期：Updated Mar 5, 2026
    const verbAbsoluteDateRegex = /^(updated|created|modified|...)\s+(Jan|Feb|Mar|...)\s+\d{1,2},?\s+\d{4}$/i;
    
    return verbAbsoluteDateRegex.test(text);
}
```

**匹配示例**：
```javascript
isDateTimeLine("Updated Mar 5, 2026") → true ✓
isDateTimeLine("Created January 1, 2024") → true ✓
isDateTimeLine("Modified Dec 25, 2023") → true ✓
```

## 边界情况

### 1. 三行文本

```
HTML:
<div>
  Last
  <span>updated</span>
  <span>2 days ago</span>
</div>

合并后："Last\nupdated\n2 days ago"
→ "Last updated 2 days ago"
→ isDateTimeLine("Last updated 2 days ago") → false ✓

原因：
- 正则要求以动词开头（updated, created...）
- "Last updated..." 以 "Last" 开头，不匹配
- 这是普通句子，应该翻译 ✓
```

### 2. 多余的空格

```
HTML:
<div>
  Updated
  <span>   15   hours   ago   </span>
</div>

合并后："Updated\n   15   hours   ago   "
规范化后：
- lines = ["Updated", "15   hours   ago"]
- combinedText = "Updated 15   hours   ago"
- isDateTimeLine("Updated 15   hours   ago") → false ❌

问题：
- 正则中的 \s+ 匹配 1 个或多个空白字符
- 但 "15   hours   ago" 中间有多个空格
- \s+ 可以匹配多个空格，所以仍然匹配 ✓

测试：
/^\s+\d+\s+(second|minute|hour|day|week|month|year)s?\s+ago$/i
.test("15   hours   ago") → true ✓
```

### 3. 混合内容

```
HTML:
<div>
  Updated 2 days ago
  <span>by John</span>
</div>

合并后："Updated 2 days ago\nby John"
→ lines = ["Updated 2 days ago", "by John"]
→ combinedText = "Updated 2 days ago by John"
→ isDateTimeLine("Updated 2 days ago by John") → false ✓

原因：
- 正则要求以 "ago" 结尾
- "Updated 2 days ago by John" 以 "John" 结尾
- 这是普通句子，应该翻译 ✓
```
