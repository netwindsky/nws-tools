# 表格翻译布局修复：根本解决方案

## 问题描述

**现象**：
翻译表格时，整个表格的行被压缩成一列，所有单元格都垂直堆叠。

**错误的 HTML 结构**：
```html
<tr>
  <td>
    <div class="nws-bilingual-wrapper">  <!-- ← 问题：wrapper 包裹了 TD 内容 -->
      <span>UI Designer</span>
      <div class="nws-translation-style">
        <span>UI 设计师</span>
      </div>
    </div>
  </td>
  <td>Visual design...</td>
</tr>
```

**问题**：
- wrapper 的 `display: grid` 会改变布局
- 即使使用 `display: block`，wrapper 也会破坏 TD 的 `table-cell` 布局
- 整个表格从多列变成单列垂直排列 ❌

---

## 根本原因分析

### 问题 1：翻译了错误的元素

**PageManager 的遍历逻辑**：
```javascript
processElements(root) {
    const walker = document.createTreeWalker(
        root,
        NodeFilter.SHOW_ELEMENT,
        {
            acceptNode: (node) => {
                if (this.hasDirectText(node)) {
                    return NodeFilter.FILTER_ACCEPT;  // ← 接受有文本的元素
                }
                return NodeFilter.FILTER_SKIP;
            }
        }
    );
    
    while (walker.nextNode()) {
        nodesToProcess.push(walker.currentNode);  // ← 可能是 TR, TD, TH 等
    }
}
```

**问题**：
- 如果 TR 有直接文本节点，会被翻译
- 如果 TD 有文本，会被翻译
- 翻译时会包裹 wrapper，破坏表格布局

### 问题 2：wrapper 破坏表格布局

**即使使用 block 布局**：
```css
.nws-bilingual-wrapper {
    display: block !important;  /* ← 仍然会改变布局 */
}
```

**HTML 结构**：
```html
<td>
  <div class="nws-bilingual-wrapper">  <!-- display: block -->
    原文
    <div class="nws-translation-style">译文</div>
  </div>
</td>
```

**问题**：
- TD 的子元素变成了 wrapper（block 元素）
- wrapper 的高度会影响 TD 的高度
- 但 wrapper 不会破坏 TD 的 `table-cell` 属性
- **真正的问题**：如果 TR 被翻译并包裹，会破坏整行

### 问题 3：没有跳过表格结构元素

**原始的 `isSkippableElement`**：
```javascript
const skipTags = new Set([
    'SCRIPT', 'STYLE', 'NOSCRIPT', 'IFRAME', 'NAV', 'FOOTER', 'HEADER',
    'PRE', 'CODE', 'SVG', 'IMG', 'TEXTAREA', 'INPUT', 'SELECT', 'OPTION',
    'BUTTON', 'CANVAS', 'VIDEO', 'AUDIO'
    // ❌ 缺少表格元素
]);
```

**结果**：
- TABLE, TR, TBODY, THEAD 等没有被跳过
- 这些结构元素可能被翻译并包裹
- 破坏表格布局

---

## 修复方案

### 方案 1：跳过表格结构元素 ✅

**修改 `isSkippableElement`**：
```javascript
const skipTags = new Set([
    'SCRIPT', 'STYLE', 'NOSCRIPT', 'IFRAME', 'NAV', 'FOOTER', 'HEADER',
    'PRE', 'CODE', 'SVG', 'IMG', 'TEXTAREA', 'INPUT', 'SELECT', 'OPTION',
    'BUTTON', 'CANVAS', 'VIDEO', 'AUDIO',
    // 新增：表格结构元素
    'TABLE', 'TR', 'TBODY', 'THEAD', 'TFOOT'
]);

if (skipTags.has(element.tagName)) return true;
```

**效果**：
- TABLE, TR, TBODY, THEAD, TFOOT 不会被翻译
- 只翻译 TD/TH 内的文本内容

### 方案 2：对 TD/TH 使用不同的翻译策略 ✅

**修改 `applyBilingualTranslation`**：
```javascript
applyBilingualTranslation(element, translatedText) {
    // 检查是否是表格单元格
    const isTableCell = element.tagName === 'TD' || element.tagName === 'TH';
    
    // 移除旧的译文
    const existingTranslation = element.querySelector('.nws-translation-style');
    if (existingTranslation) {
        existingTranslation.remove();
    }
    
    // 创建译文容器
    const block = document.createElement('div');
    block.className = 'nws-translation-style';
    
    // ... 创建译文段落 ...
    
    if (isTableCell) {
        // 表格单元格：直接追加译文，不包裹原文
        element.appendChild(block);
        this.blockNodeCache.set(element, block);
    } else {
        // 非表格元素：使用 wrapper 包裹
        let wrapper = element.closest('.nws-bilingual-wrapper');
        
        if (!wrapper) {
            wrapper = document.createElement('div');
            wrapper.className = 'nws-bilingual-wrapper';
            
            if (element.parentNode) {
                element.parentNode.insertBefore(wrapper, element);
                wrapper.appendChild(element);  // 移动原文到 wrapper
            }
        }
        
        wrapper.appendChild(block);
        this.blockNodeCache.set(element, wrapper);
    }
}
```

**关键改进**：
1. **不包裹 TD/TH**：直接在单元格内追加译文
2. **保持原文位置**：原文仍在 TD/TH 内
3. **译文追加在后面**：作为 TD/TH 的子元素

### 方案 3：调整 CSS 样式 ✅

**新增表格单元格译文样式**：
```css
/* 表格单元格内的译文样式 */
td .nws-translation-style,
th .nws-translation-style {
    display: block !important;
    margin-top: 6px !important;
    padding-top: 6px !important;
    border-top: 1px solid rgba(255, 255, 255, 0.12) !important;
    width: 100% !important;
}

/* 保持单元格布局 */
td.nws-translation-style,
th.nws-translation-style {
    display: table-cell !important;
}
```

**作用**：
- 译文在单元格内以 block 显示
- 用细线与原文分隔
- 不影响 TD/TH 的 `table-cell` 布局

## 技术细节

### 1. 为什么跳过 TR 而不是 TD？

**原因**：
- TR 是行容器，翻译 TR 会影响整行
- TD 是单元格，翻译 TD 只影响单个单元格
- 但翻译 TD 时不能包裹，只能追加译文

**跳过列表**：
```javascript
'TABLE', 'TR', 'TBODY', 'THEAD', 'TFOOT'
```

**不跳过**：
```javascript
// TD, TH 不跳过，允许翻译
```

### 2. 为什么 TD/TH 不包裹？

**包裹的问题**：
```html
<td>
  <div class="nws-bilingual-wrapper">  <!-- ← 问题 -->
    原文
    <div class="nws-translation-style">译文</div>
  </div>
</td>
```

- wrapper 是 block 元素
- wrapper 会成为 TD 的唯一子元素
- 虽然 TD 仍是 `table-cell`，但 wrapper 的高度会影响布局
- 如果 wrapper 有 margin/padding，会撑大单元格

**不包裹的好处**：
```html
<td>
  原文
  <div class="nws-translation-style">译文</div>  <!-- ← 直接追加 -->
</td>
```

- 原文保持文本节点
- 译文作为普通子元素
- 不影响 TD 的 `table-cell` 属性
- 布局稳定

### 3. 如何避免重复翻译？

**移除旧译文**：
```javascript
const existingTranslation = element.querySelector('.nws-translation-style');
if (existingTranslation) {
    existingTranslation.remove();
}
```

**作用**：
- 如果 TD 已经有译文，先移除
- 再添加新的译文
- 避免重复叠加

## 边界情况

### 1. 嵌套表格

```html
<table>
  <tr>
    <td>
      <table>
        <tr>
          <td>Nested</td>
        </tr>
      </table>
    </td>
  </tr>
</table>
```

**处理**：
- 外层 TD 和内层 TD 都会被翻译
- 每个 TD 都直接追加译文
- 不影响嵌套结构

✅ **正常工作**

### 2. 跨行/跨列单元格

```html
<table>
  <tr>
    <td rowspan="2">Rowspan</td>
    <td>Cell 1</td>
  </tr>
  <tr>
    <td>Cell 2</td>
  </tr>
</table>
```

**处理**：
- 每个 TD 独立翻译
- 译文追加在各自 TD 内
- 不影响 rowspan/colspan

✅ **正常工作**

### 3. 空单元格

```html
<table>
  <tr>
    <td></td>
    <td>Content</td>
  </tr>
</table>
```

**处理**：
- 空 TD 没有文本节点
- `hasDirectText()` 返回 false
- 不会被翻译

✅ **正常跳过**
