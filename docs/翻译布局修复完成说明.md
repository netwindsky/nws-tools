# 翻译布局修复：强制上下结构显示

## 修复概述

**问题**：翻译结果显示为左右结构，而非标准的上下结构。

**原因**：父元素使用 flex/grid 布局，导致作为兄弟节点插入的译文被挤到右侧。

**解决方案**：使用 wrapper 包裹原文和译文，通过 CSS Grid 强制上下布局。

---

## 修改内容

### 1. 新增 CSS 样式

**文件**：`TranslationView.js:212-219`

```css
/* 双语包裹器：强制上下布局 */
.nws-bilingual-wrapper {
    display: grid !important;
    grid-template-columns: 1fr !important;  /* 单列布局 */
    grid-template-rows: auto auto !important;  /* 两行：原文 + 译文 */
    gap: 8px !important;  /* 原文和译文之间的间距 */
    margin: 8px 0 !important;
    width: 100% !important;
}
```

**效果**：
- ✅ 强制使用单列 Grid 布局
- ✅ 原文和译文分别占据两行
- ✅ 不受父元素 flex/grid 布局影响

### 2. 修改 `applyBilingualTranslation` 方法

**文件**：`TranslationView.js:522-562`

**核心逻辑**：

```javascript
applyBilingualTranslation(element, translatedText) {
    // 1. 检查是否已经在 wrapper 中
    let wrapper = element.closest('.nws-bilingual-wrapper');
    
    if (!wrapper) {
        // 2. 创建 wrapper
        wrapper = document.createElement('div');
        wrapper.className = 'nws-bilingual-wrapper';
        
        // 3. 插入 wrapper 并移动原文
        if (element.parentNode) {
            element.parentNode.insertBefore(wrapper, element);
            wrapper.appendChild(element);  // 移动原文到 wrapper
        }
    }
    
    // 4. 创建译文容器
    const block = document.createElement('div');
    block.className = 'nws-translation-style';
    // ... 填充译文内容 ...
    
    // 5. 添加到 wrapper（自动显示在原文下方）
    wrapper.appendChild(block);
    this.blockNodeCache.set(element, wrapper);
}
```

**流程图解**：

```
修改前：
┌─────────────────────────┐
│ 父元素 (display: flex)  │
│ ┌──────────────────┐   │
│ │ 原文   │  译文    │   │ ← 并排显示 ❌
│ ────────┴──────────┘   │
└─────────────────────────┘

修改后：
┌─────────────────────────┐
│ 父元素 (任意布局)       │
│ ┌────────────────────┐  │
│ │ nws-bilingual-     │  │
│ │ wrapper (grid)     │  │
│ │ ┌────────────────┐ │  │
│ │ │ 原文           │ │  │
│ │ ├────────────────┤ │  │
│ │ │ 译文           │ │  │ ← 上下显示 ✅
│ │ └────────────────┘ │  │
│ └────────────────────┘  │
└─────────────────────────┘
```

### 4. 更新 `removeTranslationBlock` 方法

**文件**：`TranslationView.js:623-644`

**核心逻辑**：

```javascript
removeTranslationBlock(element) {
    const cached = this.blockNodeCache.get(element);
    if (cached && cached.parentNode) {
        // 如果缓存的是 wrapper，需要还原原文
        if (cached.classList.contains('nws-bilingual-wrapper')) {
            const originalElement = cached.querySelector(':scope > *:first-child');
            if (originalElement && cached.parentNode) {
                cached.parentNode.insertBefore(originalElement, cached);
                cached.parentNode.removeChild(cached);
            }
        } else {
            cached.parentNode.removeChild(cached);
        }
    }
    this.blockNodeCache.delete(element);
}
```

**作用**：
- ✅ 删除翻译时，正确还原原文到 DOM
- ✅ 清理 wrapper 容器
- ✅ 兼容旧的直接插入方式

## 技术细节

### 为什么选择 CSS Grid？

**方案对比**：

| 方案 | 优点 | 缺点 |
|------|------|------|
| `display: block` | 简单 | 受父元素 flex 布局影响 |
| `flex-basis: 100%` | 部分有效 | 不够可靠，可能有兼容性问题 |
| `clear: both` | 清除浮动 | 对 flex/grid 布局无效 |
| **CSS Grid (wrapper)** | ✅ 完全控制布局<br>✅ 不受父元素影响<br>✅ 语义清晰 | 需要修改 DOM 结构 |

### Grid 布局详解

```css
.nws-bilingual-wrapper {
    display: grid !important;  /* 启用 Grid 布局 */
    grid-template-columns: 1fr !important;  /* 单列：占满宽度 */
    grid-template-rows: auto auto !important;  /* 两行：高度自适应 */
    gap: 8px !important;  /* 行间距 */
    width: 100% !important;  /* 占满父元素宽度 */
}
```

**效果**：
- 第一行：原文（自动高度）
- 第二行：译文（自动高度）
- 间距：8px

### 为什么使用 `!important`？

**原因**：
- ✅ 覆盖父元素的布局规则
- ✅ 防止被其他样式影响
- ✅ 确保布局行为一致

**结论**：所有现代浏览器都支持 CSS Grid。

### 降级方案

如果浏览器不支持 Grid，wrapper 会回退到 `display: block`，原文和译文仍会上下显示（虽然间距可能不完美）。
