# 翻译并发测试指南

## 测试目的

验证前端翻译是否真正利用后台的并发能力（`parallel: 8`）。

## 测试方法

### 方法 1：浏览器控制台日志

1. **打开浏览器开发者工具**（F12）
2. **切换到 Console 面板**
3. **清空控制台**（Ctrl+L 或点击清空按钮）
4. **打开一个包含大量文本的网页**（如 GitHub 仓库页面）
5. **启用页面翻译**
6. **观察控制台输出**

### 方法 2：网络面板观察

1. **打开浏览器开发者工具**（F12）
2. **切换到 Network 面板**
3. **启用页面翻译**
4. **观察请求发送模式**

#### 预期网络请求模式

**正确的并发行为**：
- 同时看到 8 个 `chat/completions` 请求处于 `pending` 状态
- 请求几乎同时发送（时间戳相差 < 100ms）
- 响应在不同时间返回（取决于翻译耗时）

**错误的串行行为**：
- 每次只有 1 个 `chat/completions` 请求
- 必须等待前一个请求完成后才发送下一个
- 请求时间戳相差较大（> 2 秒）

### 方法 3：性能计时

在控制台执行以下代码：

```javascript
// 重置计数器
window.translationStats = {
    submitted: 0,
    completed: 0,
    startTime: null,
    endTime: null
};

// 监控提交
const originalEnqueue = TranslationModule.prototype.enqueueTranslation;
TranslationModule.prototype.enqueueTranslation = function(text) {
    if (!window.translationStats.startTime) {
        window.translationStats.startTime = Date.now();
    }
    window.translationStats.submitted++;
    console.log(`[统计] 提交第 ${window.translationStats.submitted} 个翻译任务`);
    return originalEnqueue.call(this, text).then(result => {
        window.translationStats.completed++;
        if (window.translationStats.completed === window.translationStats.submitted) {
            window.translationStats.endTime = Date.now();
            const duration = (window.translationStats.endTime - window.translationStats.startTime) / 1000;
            console.log(`[统计] 所有翻译完成！总时间: ${duration}秒, 总任务: ${window.translationStats.submitted}`);
            console.log(`[统计] 平均每个任务: ${duration / window.translationStats.submitted}秒`);
            console.log(`[统计] 并发效率: ${window.translationStats.submitted / duration} 任务/秒`);
        }
        return result;
    });
};

// 然后启用页面翻译，观察统计结果
```

#### 预期结果

假设每个翻译耗时 2 秒：

**并发 8 个**：
- 20 个任务，总时间约 6 秒（(20/8) * 2）
- 并发效率约 3.3 任务/秒

**串行 1 个**：
- 20 个任务，总时间约 40 秒（20 * 2）
- 并发效率约 0.5 任务/秒

## 常见问题排查

### 问题 1：日志显示队列长度始终为 1

**可能原因**：
- `IntersectionObserver` 是逐个触发回调的
- `processElements` 是逐个调用 `processElement` 的

**检查方法**：
查看 `[PageManager] IntersectionObserver` 日志，如果显示 `"1 个元素进入视口"`，说明元素是分批进入视口的。

**解决方案**：
这是正常行为。只要 `TranslationModule` 的队列系统能累积多个任务并并发处理即可。

### 问题 2：`activeRequests` 始终为 1

**可能原因**：
- `concurrentLimit` 配置未生效
- `processQueue` 的 `while` 循环有问题

**检查方法**：
在控制台检查配置：
```javascript
const module = window.NWSModules.get('TranslationModule');
console.log(module.config.concurrentLimit);  // 应该输出 8
```

**解决方案**：
如果配置不正确，检查 `TranslationModule` 的初始化逻辑。

### 问题 3：网络请求仍然是串行的

**可能原因**：
- 浏览器限制了并发请求数
- HTTP/1.1 连接数限制（通常是 6 个）
- 后台模型实际上没有并发处理

**检查方法**：
1. 检查浏览器是否使用 HTTP/2（在 Network 面板查看 Protocol 列）
2. 检查后台模型日志，确认是否同时处理多个请求

**解决方案**：
- 确保使用 HTTP/2
- 检查后台模型配置
- 考虑使用请求池管理并发

## 优化建议

### 1. 增加批量提交

如果 `IntersectionObserver` 是逐个触发回调的，可以考虑批量收集元素后再统一提交：

```javascript
// 修改 setupIntersectionObserver
setupIntersectionObserver() {
    let batchQueue = [];
    let batchTimer = null;
    
    this.intersectionObserver = new IntersectionObserver((entries) => {
        for (const entry of entries) {
            if (entry.isIntersecting) {
                batchQueue.push(entry.target);
                this.intersectionObserver.unobserve(entry.target);
            }
        }
        
        // 批量处理
        if (batchQueue.length > 0 && !batchTimer) {
            batchTimer = setTimeout(() => {
                console.log(`[PageManager] 批量处理: ${batchQueue.length} 个元素`);
                batchQueue.forEach(el => this.processElement(el));
                batchQueue = [];
                batchTimer = null;
            }, 50);  // 50ms 内收集的元素批量处理
        }
    }, {
        rootMargin: '200px 0px',
        threshold: 0.01
    });
}
```

### 2. 预加载优化

增加 `rootMargin` 提前加载更多内容：

```javascript
{
    rootMargin: '500px 0px',  // 提前 500px 加载
    threshold: 0.01
}
```

### 3. 优先级队列

根据元素重要性设置翻译优先级：

```javascript
// 视口内的元素优先翻译
const isInViewport = (element) => {
    const rect = element.getBoundingClientRect();
    return rect.top >= 0 && rect.bottom <= window.innerHeight;
};

// 优先处理视口内的元素
if (isInViewport(element)) {
    this.queue.unshift({ text, resolve, reject, priority: 'high' });
} else {
    this.queue.push({ text, resolve, reject, priority: 'low' });
}
```

## 总结

通过浏览器控制台日志和网络面板观察，可以验证翻译并发是否生效：

1. ✅ **查看控制台日志**：确认队列长度和活跃请求数
2. ✅ **查看网络面板**：确认请求是否并发发送
3. ✅ **性能计时**：统计总时间和并发效率

如果发现问题，根据常见问题排查部分进行诊断和修复。
