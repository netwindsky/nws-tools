# 翻译布局问题诊断：左右结构 vs 上下结构

## 问题描述

当前翻译结果显示为**左右结构**，但标准应该是**上下结构**。

### 异常表现

```
原文在左，译文在右 → ❌ 错误
```

### 预期表现

```
原文在上，译文在下 → ✅ 正确
```

---

## 问题根源

### 1. CSS 样式分析

**当前样式定义** (`TranslationView.js:163-203`):

```css
.nws-translation-style {
    display: block !important;
    position: relative !important;
    z-index: 0;
    width: 100% !important;
    min-width: 100% !important;
    box-sizing: border-box;
    margin: 8px 0;
    padding: 8px 12px;
    white-space: pre-wrap;
    background-color: transparent;
    box-shadow: 0 0 15px rgba(0, 0, 0, 0.5); 
    border-radius: 4px;
    line-height: 1.45;
    flex-basis: 100% !important;
    flex-grow: 1 !important;
    clear: both !important;
    float: none !important;
}
```

**问题分析**：
- ✅ `display: block` - 正确，块级元素
- ✅ `width: 100%` - 正确，占满宽度
- ✅ `clear: both` - 正确，清除浮动
- ✅ `float: none` - 正确，不浮动
- ⚠️ **但是**：这些样式只应用于译文容器，**没有控制原文和译文的相对位置**

### 2. DOM 插入逻辑

**当前插入逻辑** (`TranslationView.js:537-540`):

```javascript
applyBilingualTranslation(element, translatedText) {
    // ... 创建译文容器 block ...
    
    if (element.parentNode) {
        element.parentNode.insertBefore(block, element.nextSibling);
        //                                  ↑插入到原文的下一个兄弟节点
        this.blockNodeCache.set(element, block);
    }
}
```

**DOM 结构**：

```html
<!-- 当前结构 -->
<p>原文内容</p>
<div class="nws-translation-style">
    <p>译文内容</p>
</div>
```

**问题**：
- ✅ 译文确实插入在原文之后（作为下一个兄弟节点）
- ⚠️ **但是**：如果父元素是**flex 布局**或**grid 布局**，兄弟节点可能会并排显示！

### 3. 真正的罪魁祸首：父元素的布局方式

**常见情况**：

```css
/* 情况 1：父元素是 flex 布局 */
.parent {
    display: flex;  /* ← 子元素会并排显示 */
}

/* 情况 2：父元素是 grid 布局 */
.parent {
    display: grid;
    grid-template-columns: 1fr 1fr;  /* ← 两列布局 */
}

/* 情况 3：父元素是 inline-block */
.parent {
    font-size: 0;  /* 消除空白 */
}
```

**结果**：

```html
<!-- 如果父元素是 flex -->
<div class="parent" style="display: flex;">
    <p>原文</p>           <!-- 左 -->
    <div class="nws-translation-style">  <!-- 右 -->
        <p>译文</p>
    </div>
</div>
```

## 解决方案

### 方案 1：强制译文容器换行（推荐）

**修改 CSS 样式**：

```css
.nws-translation-style {
    display: block !important;
    /* 新增：强制换行 */
    flex-basis: 100% !important;
    width: 100% !important;
    margin-top: 8px !important;  /* 与原文保持间距 */
}
```

**问题**：当前代码已经有 `flex-basis: 100%`，但可能不够。

### 方案 2：修改 DOM 结构（更可靠）

**不插入为兄弟节点，而是包裹原文**：

```javascript
applyBilingualTranslation(element, translatedText) {
    // 创建包裹容器
    const wrapper = document.createElement('div');
    wrapper.className = 'nws-bilingual-wrapper';
    wrapper.style.cssText = `
        display: flex !important;
        flex-direction: column !important;  /* 强制上下布局 */
        gap: 8px !important;
        margin: 8px 0 !important;
    `;
    
    // 克隆原文并包裹
    const originalClone = element.cloneNode(true);
    
    // 创建译文容器
    const block = document.createElement('div');
    block.className = 'nws-translation-style';
    // ... 填充译文 ...
    
    // 组装
    wrapper.appendChild(originalClone);
    wrapper.appendChild(block);
    
    // 替换原元素
    if (element.parentNode) {
        element.parentNode.replaceChild(wrapper, element);
    }
}
```

**优点**：
- ✅ 完全控制布局
- ✅ 不受父元素影响
- ✅ 结构清晰

**缺点**：
- ⚠️ 改变了 DOM 结构，可能影响其他脚本

### 方案 3：使用 CSS Grid 强制换行（最佳）

**修改 CSS**：

```css
/* 新增：双语包裹器样式 */
.nws-bilingual-wrapper {
    display: grid !important;
    grid-template-columns: 1fr !important;  /* 单列布局 */
    grid-template-rows: auto auto !important;  /* 两行 */
    gap: 8px !important;
    margin: 8px 0 !important;
}

/* 修改：译文样式 */
.nws-translation-style {
    display: block !important;
    width: 100% !important;
    margin: 0 !important;  /* 由 wrapper 控制间距 */
}
```

**修改 DOM 插入逻辑**：

```javascript
applyBilingualTranslation(element, translatedText) {
    // 检查是否已经在 wrapper 中
    const existingWrapper = element.closest('.nws-bilingual-wrapper');
    if (existingWrapper) {
        // 已有 wrapper，直接追加译文
        existingWrapper.appendChild(block);
        return;
    }
    
    // 创建 wrapper
    const wrapper = document.createElement('div');
    wrapper.className = 'nws-bilingual-wrapper';
    
    // 创建译文容器
    const block = document.createElement('div');
    block.className = 'nws-translation-style';
    // ... 填充译文 ...
    
    // 插入 wrapper 到原文位置
    if (element.parentNode) {
        element.parentNode.insertBefore(wrapper, element);
        wrapper.appendChild(element);  // 移动原文到 wrapper
        wrapper.appendChild(block);    // 添加译文到 wrapper
    }
}
```

## 根本原因确认

### 测试步骤

1. **检查父元素的布局方式**：

```javascript
// 在控制台执行
const element = document.querySelector('被翻译的元素');
const parentStyle = window.getComputedStyle(element.parentNode);
console.log('display:', parentStyle.display);
console.log('flex-direction:', parentStyle.flexDirection);
console.log('grid-template-columns:', parentStyle.gridTemplateColumns);
```

2. **可能的结果**：

```
情况 A: display: flex
→ 子元素并排显示

情况 B: display: grid; grid-template-columns: 1fr 1fr
→ 子元素两列布局

情况 C: display: block
→ 应该是上下布局，但如果原文是 inline 元素，也可能并排
```

### 最可能的原因

**GitHub 的列表项使用了 flex 布局**：

```html
<li class="Box-row">  <!-- display: flex -->
    <div>Updated 10 hours ago</div>  <!-- 原文 -->
    <div class="nws-translation-style">  <!-- 译文 → 被挤到右边 -->
        <div>Updated Mar 5, 2026</div>
    </div>
</li>
```

## 修复方案（最终版）

### 方案：强制包裹 + Grid 布局

**修改 `TranslationView.js`**：

1. **新增 CSS**：

```css
/* 双语包裹器：强制上下布局 */
.nws-bilingual-wrapper {
    display: grid !important;
    grid-template-columns: 1fr !important;
    grid-template-rows: auto auto !important;
    gap: 8px !important;
    margin: 8px 0 !important;
    width: 100% !important;
}
```

2. **修改 `applyBilingualTranslation`**：

```javascript
applyBilingualTranslation(element, translatedText) {
    if (!element) return;
    if (!translatedText) return;
    this.removeTranslationBlock(element);

    // 检查是否已经在 wrapper 中
    let wrapper = element.closest('.nws-bilingual-wrapper');
    
    if (!wrapper) {
        // 创建 wrapper
        wrapper = document.createElement('div');
        wrapper.className = 'nws-bilingual-wrapper';
        
        // 插入 wrapper 替换原文
        if (element.parentNode) {
            element.parentNode.insertBefore(wrapper, element);
            wrapper.appendChild(element);  // 移动原文
        }
    }
    
    // 创建译文容器
    const block = document.createElement('div');
    block.className = 'nws-translation-style';
    // ... 填充译文内容 ...
    
    // 添加到 wrapper
    wrapper.appendChild(block);
    this.blockNodeCache.set(element, wrapper);
}
```

## 总结

### 问题

- ❌ 译文显示在原文右侧（左右结构）
- ❌ 不符合标准的上下结构布局

### 原因

- 🎯 **父元素使用 flex/grid 布局**，导致兄弟节点并排显示
- 🎯 译文容器作为兄弟节点插入，被父元素的布局规则影响

### 解决

- ✅ **创建 wrapper 包裹原文和译文**
- ✅ **使用 `display: grid` 强制上下布局**
- ✅ **不受父元素布局影响**

---

**核心思想：通过包裹器隔离父元素的布局影响，确保译文始终在原文下方。**
