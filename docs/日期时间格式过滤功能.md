# 日期时间格式过滤功能

## 功能概述

新增日期时间格式检测，自动过滤各种日期时间表达，避免无意义的翻译。

**示例**：
- ✅ `Updated 15 hours ago` → 不翻译
- ✅ `Mar 5, 2026` → 不翻译
- ✅ `10 minutes ago` → 不翻译
- ✅ `2024-01-15` → 不翻译

---

## 支持的日期时间格式

### 1. 相对时间格式

**模式**：`[动作] + [数字] + [时间单位] + ago`

**示例**：
```
Updated 15 hours ago
Created 10 minutes ago
Modified 2 days ago
Posted 3 weeks ago
Published 1 month ago
Deleted 5 years ago
Added 30 seconds ago
Removed 7 days ago
```

**正则**：
```javascript
/^(updated|created|modified|posted|published|deleted|added|removed)\s+\d+\s+(second|minute|hour|day|week|month|year)s?\s+ago$/i
```

**支持的动作**：
- updated（更新）
- created（创建）
- modified（修改）
- posted（发布）
- published（发表）
- deleted（删除）
- added（添加）
- removed（移除）

**支持的时间单位**：
- second（秒）
- minute（分钟）
- hour（小时）
- day（天）
- week（周）
- month（月）
- year（年）

---

### 2. 绝对日期格式

**模式**：`[月份] + [日期]，[年份]`

**示例**：
```
Mar 5, 2026
January 1, 2024
Dec 25, 2023
February 28, 2024
September 15, 2023
```

**正则**：
```javascript
/^(Jan|Feb|Mar|Apr|May|Jun|Jul|Aug|Sep|Oct|Nov|Dec|January|February|March|April|May|June|July|August|September|October|November|December)\s+\d{1,2},?\s+\d{4}$/i
```

**支持的月份**：
- 缩写：Jan, Feb, Mar, Apr, May, Jun, Jul, Aug, Sep, Oct, Nov, Dec
- 全称：January, February, March, April, May, June, July, August, September, October, November, December

---

### 3. 数字日期格式

**模式**：`YYYY-MM-DD` 或 `MM/DD/YYYY` 或 `DD-MM-YYYY`

**示例**：
```
2024-01-15
2023/12/25
01/15/2024
15-01-2024
1/5/2024
```

**正则**：
```javascript
/^\d{4}[-/]\d{1,2}[-/]\d{1,2}$|^\d{1,2}[-/]\d{1,2}[-/]\d{4}$|^\d{1,2}[-/]\d{1,2}[-/]\d{2,4}$/
```

**支持的格式**：
- ISO 格式：2024-01-15
- 美国格式：01/15/2024
- 欧洲格式：15-01-2024
- 简写年份：1/5/24

---

### 4. 时间格式

**模式**：`HH:MM[:SS] [AM/PM]`

**示例**：
```
10:30 AM
14:30
3:45 PM
10:30:45
9:00
```

**正则**：
```javascript
/^\d{1,2}:\d{2}(:\d{2})?\s*(AM|PM|am|pm)?$/
```

**支持的格式**：
- 12 小时制：10:30 AM, 3:45 PM
- 24 小时制：14:30, 09:00
- 带秒：10:30:45

---

### 5. 日期时间组合

**模式**：`[日期] + [时间]`

**示例**：
```
2024-01-15 10:30 AM
Mar 5, 2026 14:30
January 1, 2024 9:00 PM
2023/12/25 00:00
```

**正则**：
```javascript
/^((Jan|Feb|Mar|Apr|May|Jun|Jul|Aug|Sep|Oct|Nov|Dec|January|February|March|April|May|June|July|August|September|October|November|December)\s+\d{1,2},?\s+\d{4}|\d{4}[-/]\d{1,2}[-/]\d{1,2})\s+\d{1,2}:\d{2}(:\d{2})?\s*(AM|PM|am|pm)?$/i
```

---

### 6. 中文日期时间

**模式**：`YYYY 年 MM 月 DD 日 [HH:MM[:SS]]`

**示例**：
```
2024 年 1 月 15 日
2024 年 1 月 15 日 10:30
2023 年 12 月 25 日 14:30:45
```

**正则**：
```javascript
/^\d{4}年\d{1,2}月\d{1,2}日(\s*\d{1,2}:\d{2}(:\d{2})?)?$/
```

---

### 7. 简短时间标记

**模式**：`[数字] + [时间单位缩写]`

**示例**：
```
15h
10m
2d
3w
1y
5min
30sec
2hr
```

**正则**：
```javascript
/^\d+\s*(s|sec|m|min|h|hr|d|day|w|wk|mo|mth|y|yr)$/i
```

**支持的时间单位**：
- s, sec - 秒
- m, min - 分钟
- h, hr - 小时
- d, day - 天
- w, wk - 周
- mo, mth - 月
- y, yr - 年

## 检测流程

### 在 `_shouldTranslateTextForPage` 中的位置

```javascript
_shouldTranslateTextForPage(text) {
    // 1. URL 检测
    if (this.isURLWithDescription(text)) return false;
    
    // 2. 邮箱检测
    if (/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(text)) return false;
    
    // 3. 文件名检测
    if (this.isFileName(text)) return false;
    
    // 4. 路径检测
    if (this.isPath(text)) return false;
    
    // 5. 代码标识符检测
    if (this.isCodeIdentifier(text)) return false;
    
    // 6. 命令检测
    if (this.isCommand(text)) return false;
    
    // 7. 【新增】日期时间检测 ← 新增
    if (this.isDateTime(text)) return false;
    
    // 8. 无意义内容检测
    if (this.isMeaninglessContent(text)) return false;
    
    // ... 其他检测
    
    return true;
}
```

### 优先级

**第 7 步**，在技术内容检测之后，无意义内容检测之前。

**理由**：
1. 日期时间是**有意义的内容**，不是无意义内容
2. 日期时间是**通用格式**，不需要翻译
3. 优先级高于语言判断（避免被当作英文短语翻译）

## 边界情况

### 1. 大小写敏感

```javascript
isDateTime("UPDATED 15 HOURS AGO") → true ✓ (不区分大小写)
isDateTime("updated 15 Hours Ago") → true ✓
isDateTime("MAR 5, 2026") → true ✓
```

### 2. 空格容忍度

```javascript
isDateTime("Updated  15  hours  ago") → false ❌ (空格过多，不匹配)
isDateTime("Updated 15 hours ago") → true ✓ (标准空格)
```

**理由**：过度容忍可能导致误判普通句子。

### 3. 单复数

```javascript
isDateTime("1 hour ago") → true ✓ (单数)
isDateTime("2 hours ago") → true ✓ (复数)
isDateTime("1 days ago") → true ✓ (虽然语法错误，但仍匹配)
```

### 4. 混合内容

```javascript
isDateTime("Updated 15 hours ago and 10 minutes ago") → false ✓ (不是完整匹配)
isDateTime("15 hours ago") → true ✓ (纯时间格式)
```

2. absoluteDateRegex

### 性能分析

**优点**：
- ✅ 正则表达式简单，匹配快速

**缺点**：
- ⚠️ 增加 1 次方法调用
- ⚠️ 最多执行 7 个正则测试

**总体影响**：**可忽略不计**（微秒级别）
